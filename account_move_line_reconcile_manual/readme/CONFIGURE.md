Write-off models are optional: they prefill the journal, reference, account and analytic
distribution of a write-off.

1.  Go to *Invoicing \> Configuration \> Accounting \> Write-off Models*.
2.  Create a model with a **Write-off Reference**, an **Expense Write-off Account**, an
    **Income Write-off Account** and a **Write-off Journal**. Optionally, set the
    **Analytic for Expense** and **Analytic for Income**.
