This module imports the Stripe payouts paid to your bank account as
journal entries, to reconcile them with the customer invoices and the
bank statement.

For each Stripe payout, the import creates one journal entry in the
Stripe journal, with:

- one line per Stripe balance transaction of the payout (payments on the
  credit side, refunds on the debit side);
- one fee line per type of Stripe fee, on the commission account of the
  journal;
- the payout counterpart, on the account of the journal.

The reference of the journal entry is the id of the Stripe payout. A
payout already imported is never imported again, and a payout still
pending or in transit is imported once paid.

Configuration
=============

To configure this module, you need to:

1. Go to *Sales > Configuration > Online Payments > Payment Providers*,
   open the Stripe provider of your company and fill in its *Secret
   Key*. Each company uses the Stripe provider of its own. The key must
   be a secret key (``sk_...``) or a restricted key (``rk_...``), not
   the publishable key (``pk_...``). The import only reads this key: the
   provider can stay *Disabled* when Stripe is not a payment method of
   the website.
2. Go to *Accounting > Configuration > Journals* and create a Stripe
   journal of type *Bank*: tick *Journal used for import*, set *Type of
   import* to *Stripe*, and fill in the *Commission account*, the
   *Receivable/Payable Account* and the *Bank/Payment Office partner*.
3. Optionally, activate the scheduled action *Import Stripe
   Deposit/Payout* in *Settings > Technical > Automation > Scheduled
   Actions* to import the payouts every day.

The Stripe account must use automatic payouts (daily, weekly or monthly
schedule): Stripe does not list the transactions of a manual or instant
payout, so the import skips these payouts and logs a warning. Record
them by hand.

Usage
=====

To use this module, you need to:

1. Go to *Accounting > Accounting > Import Batch File*.
2. Select the Stripe journal: no file is needed. *Import From* shows the
   date from which the payouts are imported.
3. Click on *Import*: one journal entry is created per Stripe payout
   paid since that date and not imported yet.
